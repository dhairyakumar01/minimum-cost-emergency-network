Mathematical Rigor & Balanced Optimization Equivalence

Formal disclosure of the single-agency transit cost proportionality theorem.

In the Emergency Response Simulation, vehicle transit fuel cost is modeled strictly by:

Cij = Dij × Ra

Cnorm = Dnorm &implies; Wijbalanced = 0.50 Tnorm + 0.25 Dnorm + 0.25 Cnorm = 0.50 Tnorm + 0.50 Dnorm

System Methodology & Mathematical Foundations

Complete documentation of graph theory models, statutory fuel price benchmarks, and routing architecture.

1. Graph-Theoretic Problem Formulation

Complete graph modeling of municipal emergency infrastructure.

The municipal communication infrastructure is represented as a weighted undirected graph G = (V, E, w), where:

  • V is the set of all registered emergency facilities in Bengaluru (|V| = 1,255).
  • E is the complete set of unordered facility pairs (|E| = |V|(|V| - 1)/2 = 786,885 edges).
  • w(u, v) is the spherical Haversine geodesic distance computed using Earth radius R = 6,371.0088 km.

A Minimum Spanning Tree (MST) T = (V, ET) is an acyclic subgraph spanning all 1,255 vertices with exactly |V| - 1 = 1,254 edges such that total weight ∑ w(e) is minimized.

3. Algorithmic Dualities: Prim's Cut Property vs Kruskal's Cycle Property

Foundations of correctness in discrete optimization.

Prim's Cut Property: At each iteration, for any cut (S, V \ S) separating the current tree component S from unvisited vertices, the minimum-weight crossing edge must belong to the MST.

Kruskal's Cycle Property: For any cycle in graph G, the edge with the strictly maximum weight cannot belong to any minimum spanning tree. Kruskal greedily selects edges in non-decreasing weight order, accepting only those whose endpoints belong to disjoint sets.

Uniqueness Invariant: Despite differing execution trajectories, both algorithms produce the identical total tree length of 480.1784 km across Bengaluru.
