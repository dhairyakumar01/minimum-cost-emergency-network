1 Graph-Theoretic Problem Formulation & Complete Graph K₁₂₅₅
▼

The municipal emergency network is modeled as a weighted undirected graph G = (V, E, w), where:

  • V is the set of all registered emergency facilities in Bengaluru (|V| = 1,255).
  • E is the complete set of unordered facility pairs (|E| = |V|(|V| - 1)/2 = 786,885 edges).
  • w(u, v) is the spherical Haversine geodesic distance computed using Earth radius R = 6,371.0088 km.

A Minimum Spanning Tree (MST) T = (V, ET) is an acyclic subgraph spanning all 1,255 vertices with exactly |V| - 1 = 1,254 edges such that total weight ∑ w(e) is minimized.

2 Dual-Layer Infrastructure Model: Backbone vs Vehicular Dispatch
▼

The system maintains a strict conceptual separation between two distinct operational layers:

Layer 1 • Communication Topology

Minimum Spanning Tree (MST) Backbone

1,254 optical/RF transmission links connecting all 1,255 facilities (480.1784 km total length). Computed over K₁₂₅₅ to minimize municipal transmission infrastructure cost.

Layer 2 • Vehicular Transit

Physical Road Transit Network

Surface roadway network traversed by emergency response vehicles (ambulances, police cruisers, fire engines). Governed by one-way systems, turn restrictions, and road speed limits (Droad ≥ Dhaversine).

3 Prim's Algorithm & The Cut Property
▼

Cut Property Theorem: For any cut (S, V \ S) partitioning the graph, the minimum-weight crossing edge across the cut belongs to every minimum spanning tree.

Prim's algorithm starts from an arbitrary root vertex, maintaining visited set S and priority queue Q of crossing edges. At each step, it greedily accepts the minimum crossing link, growing the tree until |S| = |V|.

4 Kruskal's Algorithm & The Cycle Property
▼

Cycle Property Theorem: For any simple cycle in graph G, the strictly maximum-weight edge cannot belong to any minimum spanning tree.

Kruskal's algorithm sorts all 786,885 candidate edges in non-decreasing weight order, greedily adding each edge using a Disjoint Set Union (DSU) data structure with union-by-rank and path compression, skipping chords whose endpoints belong to the same component.

5 LCA Binary-Lifting Cycle Property Verification Oracle
▼

To provide an absolute mathematical proof of optimality, an independent Lowest Common Ancestor (LCA) binary-lifting verifier tests every single non-tree chord (785,631 candidate edges) against the tree path maximum:

∀ (u, v) ∉ ET,   w(u, v) ≥ max_edge_on_tree_path(u, v)

Result: 0 cycle violations at numerical tolerance 10⁻⁹ km, formally certifying that the 480.1784 km spanning tree is mathematically optimal.

6 Three Discrete Optimization Modes & Cost-Distance Isomorphism
▼

The network backbone supports three discrete optimization modes: Mode 1 (Minimum Time ST), Mode 2 (Minimum Road Distance SD), and Mode 3 (Supported Compromise Ne).

Cost-Distance Isomorphism Theorem: In any single-agency emergency dispatch run, vehicle operating fuel cost is modeled strictly as Cuv = Duv × Ra, where Ra is the per-kilometer fuel rate parameter.

Cuv ∝ Duv &implies; argmin ∑ Cuv ≡ argmin ∑ Duv

Because multiplying all edge weights by an invariant positive scalar Ra preserves pairwise edge-weight orderings, an independent minimum fuel-cost objective generates the exact same minimum spanning tree as Mode 2. Hence, fuel cost is evaluated as a metric rather than a separate optimization mode.

8 Engineering Limitations & Single-Edge Partition Vulnerability
▼

By mathematical definition, any spanning tree contains exactly zero cycles. As an acyclic network ($k=1$ edge connectivity), severing any single link partitions the network into two disconnected components. In real-world telecommunication deployments, biconnected or 2-edge-connected augmentation is recommended to prevent single-point failures.
